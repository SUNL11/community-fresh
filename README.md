# 社区生鲜终端 AI 视觉品控与损耗智能统计工具

基于计算机视觉与深度学习技术的生鲜品质自动检测与损耗管理平台，面向社区生鲜零售终端（社区团购自提点、生鲜超市等），实现非接触式的商品品质评级、损耗自动统计与智能预警。

## 核心功能

- **视觉品控**：利用摄像头采集生鲜商品图像，通过 AI 模型自动识别外观缺陷、成熟度、新鲜度，输出品质评级
- **损耗统计**：自动记录和统计每日/每周/每月的损耗商品类别、数量、金额，生成可视化报表
- **智能预警**：基于历史损耗数据与品控趋势，对高损耗品类、库存周转异常等进行预警
- **数据看板**：提供直观的管理仪表盘，实时展示品控通过率、损耗率、Top 损耗品类等关键指标

## 技术栈

- **深度学习框架**：PyTorch / TensorFlow
- **计算机视觉**：OpenCV、图像分类 / 目标检测模型
- **后端服务**：Python（FastAPI / Flask）
